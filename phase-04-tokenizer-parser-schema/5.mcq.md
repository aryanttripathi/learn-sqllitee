# Phase 4 — MCQ (25 questions)

1. SQLite's parser generator is:
   a) bison  b) ANTLR  c) Lemon (`tool/lemon.c`)  d) a hand-written recursive descent parser

2. Lemon's `%destructor` exists to:
   a) free partially built tree nodes on a syntax error  b) close cursors
   c) destroy the schema  d) handle DROP TABLE

3. Keyword recognition uses:
   a) a linear scan  b) a generated perfect hash in `keywordhash.h`  c) a binary search  d) `strcmp` chain

4. `%fallback ID ABORT ACTION ...` means:
   a) those keywords are deprecated  b) they may be used as identifiers when unambiguous
   c) they cause parse errors  d) they are reserved

5. Whitespace and comments reach the parser as:
   a) TK_SPACE tokens  b) they are skipped in `sqlite3RunParser` before the parser sees them
   c) TK_COMMENT  d) part of the next token

6. `"name"` in SQL is:
   a) always a string  b) an identifier, falling back to a string literal if it resolves to nothing (DQS)
   c) always an error  d) a blob

7. In a resolved `Expr`, `iTable` holds:
   a) the root page  b) the cursor number of the table  c) the column index  d) the rowid

8. `Expr.iColumn == -1` means:
   a) error  b) the rowid  c) the first column  d) NULL

9. `SrcItem.colUsed` is:
   a) a row count  b) a bitmask of referenced columns, used to detect covering indexes
   c) a cursor  d) an affinity string

10. Correlated subqueries are detected by:
    a) a keyword  b) `nRef` incrementing on an *outer* NameContext during name resolution
    c) the planner  d) the tokenizer

11. `Table.tnum` is:
    a) the table number  b) the root page of its b-tree  c) the number of rows  d) a hash

12. `Index.aiColumn[i] == -2` means:
    a) rowid  b) an expression index column  c) descending  d) invalid

13. SQLite stores the schema on disk as:
    a) a binary catalog  b) the original CREATE statement text in `sqlite_schema.sql`
    c) protobuf  d) a separate file

14. `sqlite3InitCallback()` re-parses each CREATE statement with:
    a) `db->init.busy=1` and a fixed root page from the schema row  b) a fresh root page
    c) a different grammar  d) no parser

15. `SQLITE_SCHEMA` means:
    a) invalid schema  b) the cached schema is stale; the statement must be re-prepared
    c) schema locked  d) a DDL statement was run

16. Affinity of a column declared `"FLOATING POINT"` is:
    a) REAL  b) INTEGER (it contains "INT")  c) NUMERIC  d) TEXT

17. Affinity of a column with an empty declared type is:
    a) TEXT  b) BLOB (none)  c) NUMERIC  d) INTEGER

18. `SELECT '1'=1;` returns:
    a) 1  b) 0 — no affinity is applied between two literals  c) NULL  d) error

19. Collation precedence puts first:
    a) BINARY  b) an explicit COLLATE on the left operand  c) the right column's collation  d) NOCASE

20. `sqlite3NestedParse()` is used to:
    a) parse subqueries  b) let SQLite generate and compile SQL for its own DDL
    c) parse triggers  d) handle recursion

21. `#3` inside a nested-parse SQL string means:
    a) comment  b) the value in VDBE register 3  c) column 3  d) parameter 3

22. Triggers are compiled as:
    a) inline code always  b) sub-programs invoked with `OP_Program`
    c) separate statements  d) stored procedures

23. `Token` structs:
    a) own their text  b) point into the SQL string and must be duplicated to outlive the parse
    c) are interned  d) are reference counted

24. The practical maximum number of tables in one join is ~64 because:
    a) a grammar limit  b) `Bitmask` is a 64-bit integer used for table sets
    c) cursor numbering  d) page size

25. `sqlite3TreeViewSelect()` is useful because:
    a) it runs the query  b) it prints the parse tree, so you can see resolution and rewrites
    c) it validates the schema  d) it produces EXPLAIN output

---

## Answers

1. **c** — Lemon is part of the SQLite project; it is reentrant and has destructors.
2. **a** — no memory leaks even on malformed input mid-tree.
3. **b** — generated by `tool/mkkeywordhash.c` at build time.
4. **b** — that's why `CREATE TABLE t(key, action)` works.
5. **b** — `sqlite3RunParser` `continue`s on `tokenType>=TK_SPACE`.
6. **b** — the DQS misfeature; disable it in new code.
7. **b** — the same integer that appears as `OP_OpenRead P1` in the bytecode.
8. **b** — rowid; that's how `SELECT rowid` compiles to `OP_Rowid`.
9. **b**.
10. **b**.
11. **b**.
12. **b** — `-1` is rowid, `-2` marks an expression column (`aColExpr`).
13. **b**.
14. **a** — otherwise re-parsing would allocate new root pages and destroy the database.
15. **b** — `prepare_v2` retries automatically.
16. **b** — rule 1 wins because the check order is INT, then CHAR/CLOB/TEXT, etc.
17. **b**.
18. **b** — affinity is a property of columns; two literals compare as text vs integer ⇒ 0.
19. **b**.
20. **b**.
21. **b** — a mini-extension to SQL only available to internal parses.
22. **b** — with `VdbeFrame` holding OLD/NEW registers.
23. **b**.
24. **b** — `Bitmask` (`u64`) represents sets of FROM-clause tables in the planner.
25. **b**.
