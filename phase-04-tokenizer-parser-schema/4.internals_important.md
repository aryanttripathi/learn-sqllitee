## 2. Tokenizer

### 2.1 Entry points

```c
int  sqlite3GetToken(const unsigned char *z, int *tokenType);  /* returns the LENGTH */
int  sqlite3RunParser(Parse *pParse, const char *zSql);
static int keywordCode(const char *z, int n, int *pType);      /* generated hash */
```

### 2.2 The token-code threshold

`sqlite3RunParser` filters non-grammar tokens with **one comparison**:

```c
if( tokenType>=TK_WINDOW ){     /* (>=TK_SPACE when window functions are omitted) */
   /* TK_SPACE, TK_COMMENT, TK_ILLEGAL, TK_QNUMBER, and the context-sensitive
   ** TK_WINDOW / TK_OVER / TK_FILTER live above the threshold */
}
```
Lemon assigns codes so that this works. **Never hard-code a `TK_` value** — they come from
the generated `parse.h` and change between versions.

### 2.3 Quoting

| Syntax | Token | Notes |
|---|---|---|
| `'abc'` | `TK_STRING` | `''` escapes a quote |
| `"abc"` | `TK_ID` | falls back to a string if it resolves to nothing (**DQS**); `EP_DblQuoted` records it |
| `[abc]` | `TK_ID` | MS Access / SQL Server |
| `` `abc` `` | `TK_ID` | MySQL |
| `X'414243'` | `TK_BLOB` | |
| `?`, `?NNN`, `:n`, `@n`, `$n` | `TK_VARIABLE` | |
| `-- ...`, `/* ... */` | `TK_SPACE` | never reaches the parser |

Disable DQS: `-DSQLITE_DQS=0`, or
`sqlite3_db_config(db, SQLITE_DBCONFIG_DQS_DML|_DDL, 0, 0)`.

## 3. Grammar (`parse.y`)

### 3.1 Directives

| Directive | Effect |
|---|---|
| `%token_type`, `%type` | C types for terminals and non-terminals |
| `%destructor` | frees a partially built non-terminal on a syntax error — **why parsing never leaks** |
| `%fallback ID ABORT ACTION …` | those keywords may be used as identifiers when unambiguous |
| `%left` / `%right` / `%nonassoc` | precedence, **lowest first** |
| `%wildcard ANY.` | |
| `%syntax_error` | the error-message hook |
| `%stack_overflow` | depth-limit hook |
| `%extra_argument` | passes `Parse *pParse` into every action |

### 3.2 Precedence, lowest to highest (copy from `parse.y`)

```
%left   OR.
%left   AND.
%right  NOT.
%left   IS MATCH LIKE_KW BETWEEN IN ISNULL NOTNULL NE EQ.
%left   GT LE LT GE.
%right  ESCAPE.
%left   BITAND BITOR LSHIFT RSHIFT.
%left   PLUS MINUS.
%left   STAR SLASH REM.
%left   CONCAT.
%left   COLLATE.
%right  BITNOT.
```

| Limit | Default | Guards against |

## 4. Parse-tree structures

### 4.1 `Expr`

```c
struct Expr {
  u8 op;                 /* TK_* operation code */
  char affExpr;          /* affinity, or 0 */
  u8 op2;                /* TK_COLUMN: the original op; TK_AGG_FUNCTION: parent op */
  u32 flags;             /* EP_* */
  union {
    char *zToken;        /* token text / column or function name */
    int iValue;          /* the integer value, if EP_IntValue */
  } u;
  Expr *pLeft, *pRight;
  union {
    ExprList *pList;     /* function args, IN(list)  — valid unless EP_xIsSelect */
    Select *pSelect;     /* subquery                 — valid if EP_xIsSelect */
  } x;
  int iTable;            /* CURSOR NUMBER after resolution */
  ynVar iColumn;         /* COLUMN INDEX after resolution; -1 = rowid */
  i16 iAgg;              /* index into AggInfo */
  AggInfo *pAggInfo;
  union { Table *pTab; Window *pWin; int iValue; } y;
};
```

**Three unions, three tags:**

| Union | Tag that selects the member |
|---|---|
| `u` | `EP_IntValue` ⇒ `u.iValue`, else `u.zToken` |
| `x` | `EP_xIsSelect` ⇒ `x.pSelect`, else `x.pList` |
| `y` | depends on `op` / `EP_WinFunc` / `EP_Subrtn` |

### 4.2 `EP_*` flags — the complete list

```c
#define EP_OuterON    0x000001  /* originates in the ON/USING clause of an OUTER join */
#define EP_InnerON    0x000002  /* originates in the ON/USING of an inner join */
#define EP_Distinct   0x000004  /* aggregate function with DISTINCT */
#define EP_HasFunc    0x000008  /* contains one or more functions */
#define EP_Agg        0x000010  /* contains one or more aggregate functions */
#define EP_FixedCol   0x000020  /* TK_COLUMN with a known fixed value */
#define EP_VarSelect  0x000040  /* pSelect is CORRELATED, not constant */
#define EP_DblQuoted  0x000080  /* token.z was originally in "..." */
#define EP_InfixFunc  0x000100  /* an infix function: LIKE, GLOB, etc */
#define EP_Collate    0x000200  /* the tree contains a TK_COLLATE operator */
#define EP_Commuted   0x000400  /* the comparison operator has been commuted */
#define EP_IntValue   0x000800  /* the integer value is in u.iValue */
#define EP_xIsSelect  0x001000  /* x.pSelect is valid (otherwise x.pList) */
#define EP_Skip       0x002000  /* the operator does not contribute to affinity */
#define EP_Reduced    0x004000  /* EXPR_REDUCEDSIZE bytes only */
#define EP_Win        0x008000  /* contains window functions */
#define EP_TokenOnly  0x010000  /* EXPR_TOKENONLYSIZE bytes only */
#define EP_FullSize   0x020000  /* must remain full sized */
#define EP_IfNullRow  0x040000  /* the TK_IF_NULL_ROW opcode */
#define EP_Unlikely   0x080000  /* unlikely() or likelihood() */
#define EP_ConstFunc  0x100000  /* a SQLITE_FUNC_CONSTANT or _SLOCHNG function */
#define EP_CanBeNull  0x200000  /* can be NULL despite a NOT NULL constraint */
#define EP_Subquery   0x400000  /* the tree contains a TK_SELECT */
#define EP_Leaf       0x800000  /* pLeft, pRight, u.pSelect are all NULL */
#define EP_WinFunc   0x1000000  /* TK_FUNCTION with Expr.y.pWin set */
#define EP_Subrtn    0x2000000  /* uses Expr.y.sub — TK_IN, _SELECT, _EXISTS */
#define EP_Quoted    0x4000000  /* TK_ID was originally quoted */
#define EP_Static    0x8000000  /* held in memory not obtained from malloc() */
#define EP_IsTrue   0x10000000  /* always TRUE */
#define EP_IsFalse  0x20000000  /* always FALSE */
#define EP_FromDDL  0x40000000  /* originates from sqlite_schema */
#define EP_SubtArg  0x80000000  /* is an argument to a SQLITE_SUBTYPE function */

#define EP_Propagate (EP_Collate|EP_Subquery|EP_HasFunc)   /* inherited upward */
```

The five that change behaviour most often:

| Flag | Why it matters |
|---|---|
| `EP_OuterON` | the term came from an **outer** join's ON clause; applying it to the left table produces wrong answers |
| `EP_VarSelect` | the subquery is correlated ⇒ cannot be cached or hoisted |
| `EP_IntValue` / `EP_xIsSelect` | reading the wrong union member |
| `EP_Reduced` / `EP_TokenOnly` | the struct is **truncated**; touching absent fields is a buffer overrun |
| `EP_FromDDL` | the expression came from the schema ⇒ subject to `SQLITE_DBCONFIG_TRUSTED_SCHEMA` restrictions |

`EP_Reduced`/`EP_TokenOnly` exist because schema-resident expressions (CHECK constraints,
partial-index WHERE, index expressions, DEFAULT) are duplicated with `EXPRDUP_REDUCE` to
save memory.

### 4.4 `SrcList` / `SrcItem` — the FROM clause

```c
struct SrcItem {
  Schema *pSchema; char *zDatabase, *zName, *zAlias;
  Table *pTab;           /* filled in by name resolution */
  Select *pSelect;       /* if this FROM element is a subquery */
  int addrFillSub, regReturn, regResult;
  u8 fg.jointype;        /* JT_INNER, JT_LEFT, JT_CROSS, JT_RIGHT, JT_LTORJ */
  int iCursor;           /* THE CURSOR NUMBER → becomes OP_OpenRead P1 */
  Expr *pOn; IdList *pUsing;
  Bitmask colUsed;       /* which columns are referenced → covering-index test */
  Index *pIBIndex;       /* INDEXED BY */
};
```

`iCursor` and `colUsed` are the two fields that travel furthest: `iCursor` reappears as
`Expr.iTable` and as `OP_OpenRead P1`; `colUsed` is read by `whereLoopAddBtree` in Phase 6.

### 4.5 `ExprList` — the flexible-array pattern

```c
struct ExprList {
  int nExpr;
  struct ExprList_item {
    Expr *pExpr;
    char *zEName;        /* name or alias */
    struct { unsigned done:1, reusable:1, bSorterRef:1, bNulls:1, ... } fg;
    union { struct { u16 iOrderByCol; u16 iAlias; } x; int iConstExprReg; } u;
    u8 sortFlags;        /* KEYINFO_ORDER_DESC / _BIGNULL */
  } a[1];                /* grown by realloc — header and items in ONE allocation */
};
```

## 5. Name resolution

### 5.1 `NameContext`

```c
struct NameContext {
  Parse *pParse;
  SrcList *pSrcList;      /* tables in scope at this level */
  union { ExprList *pEList; AggInfo *pAggInfo; Upsert *pUpsert; ... } uNC;
  NameContext *pNext;     /* the OUTER query's context */
  int nRef;               /* how many names resolved to THIS context */
  int nNcErr;
  int ncFlags;            /* NC_* */
};
```

**`nRef` incremented on an *outer* context is the entire correlated-subquery detector.**

### 5.2 `NC_*` flags (common ones)

```
NC_AllowAgg    aggregates are allowed here
NC_HasAgg      an aggregate was found
NC_IsCheck     inside a CHECK constraint
NC_PartIdx     inside a partial-index WHERE clause
NC_IdxExpr     inside an index expression
NC_GenCol      inside a generated-column expression
NC_UEList      uNC.pEList is valid (result-set aliases may resolve)
NC_UAggInfo    uNC.pAggInfo is valid
NC_HasWin      window functions present
NC_AllowWin    window functions are allowed here
NC_Complex     contains a subquery, function, or similar
```

The `NC_IsCheck`/`NC_PartIdx`/`NC_IdxExpr`/`NC_GenCol` group exists to forbid
non-deterministic functions and subqueries in contexts that are stored in the schema and
re-evaluated later.

### 5.3 Resolution order (`lookupName`)

```
1. zDb.zTab.zCol
2. zTab.zCol   (table name or alias)
3. zCol in any table of pSrcList      (two matches ⇒ "ambiguous column name")
4. a result-set alias                  (ORDER BY / GROUP BY / HAVING only)
5. an OUTER NameContext                ⇒ nRef++ on that context ⇒ correlated
6. error: "no such column: X"
```

Special names: `rowid` / `oid` / `_rowid_` (→ `iColumn = -1`, rowid tables only),
`NEW.` / `OLD.` inside triggers, `excluded.` inside upserts, generated columns.

### 5.4 The `Walker`

```c
struct Walker {
  Parse *pParse;
  int (*xExprCallback)(Walker*, Expr*);      /* WRC_Continue / WRC_Prune / WRC_Abort */
  int (*xSelectCallback)(Walker*, Select*);
  void (*xSelectCallback2)(Walker*, Select*);  /* called AFTER children */
  int walkerDepth;
  u16 eCode;
  union { NameContext *pNC; int n; SrcList *pSrcList; ... } u;
};
```

Users: name resolution, constant propagation, subquery flattening, WHERE push-down,
aggregate detection, `sqlite3ExprIsConstant`, `renameExpr` in `alter.c`.

## 6. Affinity and collation

### 6.1 Affinity codes

```c
#define SQLITE_AFF_NONE     0x40  /* '@' */
#define SQLITE_AFF_BLOB     0x41  /* 'A' */
#define SQLITE_AFF_TEXT     0x42  /* 'B' */
#define SQLITE_AFF_NUMERIC  0x43  /* 'C' */
#define SQLITE_AFF_INTEGER  0x44  /* 'D' */
#define SQLITE_AFF_REAL     0x45  /* 'E' */
#define SQLITE_AFF_FLEXNUM  0x46  /* 'F' */
```
These letters are what you see in `OP_MakeRecord`'s P4 affinity string, e.g. `"DBD"`.

### 6.2 The five rules (`sqlite3AffinityType`, checked **in this order**)

```
1. the declared type contains "INT"                 → INTEGER   (and STOP immediately)
2. contains "CHAR", "CLOB" or "TEXT"                → TEXT
3. contains "BLOB", or the declared type is empty   → BLOB (none)
4. contains "REAL", "FLOA" or "DOUB"                → REAL
5. otherwise                                        → NUMERIC
```

Rule 1 has no guard and `break`s the scan, which is why `"FLOATING POINT"` → INTEGER
(verified: `typeof()` returns `integer`). Rules 3–5 only apply if nothing stronger matched.

The same function also fills in `Column.szEst`, a size estimate derived from
`VARCHAR(255)`-style lengths — which the **query planner** later uses for index-scan costs.

### 6.3 Comparison affinity

```
one side INTEGER/REAL/NUMERIC and the other TEXT/BLOB
                        → numeric affinity is applied to the text side
both TEXT               → text comparison
BLOB affinity on either side with no other affinity  → no conversion
two LITERALS            → NO affinity at all   ⇒  SELECT '1'=1;  is 0
```

### 6.4 Collation precedence (`sqlite3ExprCollSeq`)

```
1. an explicit COLLATE anywhere in the LEFT operand's subtree
2. an explicit COLLATE in the RIGHT operand
3. the LEFT operand's column collation
4. the RIGHT operand's column collation
5. BINARY
```

Built-ins: `BINARY` (memcmp), `NOCASE` (ASCII-only), `RTRIM`.
**An index is only usable by a query with the same collation.**

## 7. Schema objects

```c
struct Schema {
  int schema_cookie;      /* must match hdr[40] */
  int iGeneration;        /* bumped on every schema change */
  Hash tblHash, idxHash, trigHash, fkeyHash;
  Table *pSeqTab;         /* sqlite_sequence, for AUTOINCREMENT */
  u8 file_format, enc;
  u16 schemaFlags;        /* DB_SchemaLoaded, DB_UnresetViews, DB_Empty */
};

struct Table {
  char *zName;
  Column *aCol; i16 nCol;
  Index *pIndex;          /* linked list of indexes */
  Pgno tnum;              /* the ROOT PAGE — becomes OP_OpenRead P2 */
  LogEst nRowLogEst;      /* estimated rows (from sqlite_stat1) */
  LogEst szTabRow;        /* estimated average row size */
  u32 tabFlags;           /* TF_* */
  i16 iPKey;              /* the INTEGER PRIMARY KEY column, or -1 */
  Trigger *pTrigger; FKey *pFKey;
  union { struct {...} tab; struct { Select *pSelect; } view; } u;
};

struct Index {
  char *zName;
  i16 *aiColumn;          /* table columns; -1 = rowid, -2 = an expression */
  LogEst *aiRowLogEst;    /* [0]=rows, [i]=avg rows per distinct i-col prefix */
  Table *pTable; Index *pNext;
  Pgno tnum;
  const char **azColl;    /* collation per column */
  Expr *pPartIdxWhere;    /* partial-index WHERE */
  ExprList *aColExpr;     /* expressions, for expression indexes */
  u8 onError;             /* OE_None/Abort/Replace/... for UNIQUE */
  unsigned idxType:2;     /* 0 = CREATE INDEX, 1 = UNIQUE constraint, 2 = PRIMARY KEY */
  unsigned uniqNotNull:1, isCovering:1, hasStat1:1, bNoQuery:1, ...;
};
```

Key `TF_*` flags: `TF_WithoutRowid`, `TF_HasPrimaryKey`, `TF_Autoincrement`,
`TF_HasVirtual`, `TF_HasStored`, `TF_HasGenerated`, `TF_Shadow`, `TF_HasStat1`,
`TF_Strict`, `TF_Ephemeral`, `TF_Eponymous`.

Key `COLFLAG_*` flags: `COLFLAG_PRIMKEY`, `COLFLAG_HIDDEN`, `COLFLAG_HASTYPE`,
`COLFLAG_UNIQUE`, `COLFLAG_SORTERREF`, `COLFLAG_VIRTUAL`, `COLFLAG_STORED`,
`COLFLAG_NOTAVAIL`, `COLFLAG_GENERATED`.

## 8. Schema bootstrap

```
sqlite3ReadSchema()
  └ sqlite3InitOne(db, iDb, &zErr, flags)
      1. the definition of sqlite_schema is HARD-CODED; its root page is HARD-CODED to 1
      2. read the header: page size, encoding, schema cookie, file format
      3. run: SELECT name, rootpage, sql FROM "<db>".sqlite_schema ORDER BY rowid
      4. per row → sqlite3InitCallback():
             db->init.busy    = 1
             db->init.iDb     = iDb
             db->init.newTnum = rootpage        ← use THIS page; do not allocate
             sqlite3_prepare(db, argv[3], ...)  ← RE-PARSE the CREATE statement
             db->init.busy    = 0
      5. mark DB_SchemaLoaded
```

| `db->init` field | Meaning |
|---|---|
| `busy` | "we are loading the schema, not executing DDL" |
| `newTnum` | install the object with this existing root page |
| `iDb` | which attached database |
| `orphanTrigger` | a trigger whose table is missing |
| `imposterTable` | set by `SQLITE_TESTCTRL_IMPOSTER` |

### 8.1 `SQLITE_SCHEMA`

```
DDL → hdr[40] schema cookie++ → Schema.iGeneration++
another connection's OP_Transaction compares the cookie → mismatch → SQLITE_SCHEMA
sqlite3_prepare_v2 catches it, resets the schema, re-parses, retries
   (bounded by SQLITE_MAX_SCHEMA_RETRY; the legacy sqlite3_prepare returns the error)
```

### 8.2 `sqlite3NestedParse` — internal-only SQL syntax

```c
sqlite3NestedParse(pParse,
   "UPDATE %Q." LEGACY_SCHEMA_TABLE " SET rootpage=%d WHERE #%d AND rootpage=#%d",
   db->aDb[iDb].zDbSName, iTo, iReg, iFrom);
```
`%Q` quotes an identifier; `#N` means "the value currently in VDBE register N". Neither is
available to user SQL.

## 10. Invariants

1. `Token.z` points **into the SQL text being parsed** and does not own it — anything that
   must outlive the parse is `sqlite3DbStrNDup`'d.
2. After resolution, every `TK_ID` has become `TK_COLUMN` (or an error was raised).
3. `Expr.iTable` is a cursor number, never a table id; `Expr.iColumn` is a column index,
   with `-1` meaning rowid.
4. `SF_Resolved` implies every name in the tree has been resolved.
5. An `Expr` with `EP_Reduced`/`EP_TokenOnly` is **truncated** — only the fields within
   `EXPR_REDUCEDSIZE`/`EXPR_TOKENONLYSIZE` exist.
6. A view's `Select` must be duplicated before being consumed.
7. Parse-time allocations use `sqlite3DbMalloc*` and are freed wholesale on error.
8. `db->init.busy` is set **only** while loading the schema.
9. The schema cookie in memory must match `hdr[40]` at the start of every transaction.

## 11. Gotchas

1. **Read `parse.y`, not `parse.c`.**
2. Token codes come from the generated `parse.h` and change between versions.
3. `Token` does not own its text.
4. Aliases resolve only in ORDER BY / GROUP BY / HAVING — not in WHERE.
5. `"x"` may silently become a string literal (DQS). Disable it in new code.
6. `VARCHAR(50)` does not limit length; it sets affinity **and** a size estimate.
7. `"FLOATING POINT"` → INTEGER affinity. Rule 1 wins unconditionally.
8. `SELECT '1'=1` is `0` — two literals have no affinity.
9. An index on a BINARY column cannot serve a `COLLATE NOCASE` comparison.
10. `EP_OuterON` terms must not be moved into the WHERE clause of the left table.
11. `ALTER TABLE RENAME` rewrites the **stored SQL text** of dependent objects; that is why
    `PRAGMA legacy_alter_table` exists.
12. A corrupt `sqlite_schema.sql` makes the database unopenable — repair with
    `PRAGMA writable_schema=ON`.
13. Adding a keyword means editing `tool/mkkeywordhash.c`, not a header.
14. Adding a pragma means editing `tool/mkpragmatab.tcl`, not `pragma.h`.
